# Morph Mouse website

Public static landing page for Morph Mouse. Game source and SDK credentials are not part of this repository.

- Website: https://shalokhin-artur.github.io/
- Privacy: https://shalokhin-artur.github.io/privacy.html
- Support: https://shalokhin-artur.github.io/support.html
- Authorized sellers: https://shalokhin-artur.github.io/app-ads.txt

## Preview

Run `python3 -m http.server 8765` in this directory and open http://localhost:8765.
No build, package installation, analytics or third-party font requests.

## Publish

GitHub Pages serves the root of the `main` branch. `.nojekyll` keeps the site static.
Only publish this website directory, never the private game repository or mobile service configuration.
Replace the release notice with verified store links once public listings are available.
